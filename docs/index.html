Formula


weight = params_b * dtype_bytes
kv/tok = GQA: 2*L*kv_h*d*kv_b
       | MLA: L*(latent+rope)*kv_b
kv     = kv/tok * ctx * seqs * (1 - hit*0.75)
runtime = 2.2 vLLM / 2.4 SGLang
per_gpu = weight/(tp*pp) + kv/tp + runtime
usable = vram * util
PAGES  = per_gpu > usable

fixture  Llama 3.3 70B · 4×H100 · 16K · 16 · util 0.90 · BF16
         JS pack = Go Analyze → 16 STANDS · 57.5 / 72 GB
         same · 32 seq → 32 PAGES
